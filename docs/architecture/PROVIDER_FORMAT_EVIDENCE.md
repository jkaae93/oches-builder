# Provider 설정 형식 검증 기록

확인일: 2026-11-16. 사용자 인증 변경, CLI 로그인, 모델 호출, 실제 설정 적용은 수행하지 않았다. 아래 설치 버전은 이 컴퓨터의 관찰값이며 제품의 지원 범위가 아니다.

| 대상 | 로컬 버전 관찰 | 공식 문서에서 확인한 내용 | 남은 검증 |
|---|---|---|---|
| Claude Code | 2.1.296 (`claude --version`) | [설정 문서](https://code.claude.com/docs/en/settings)는 프로젝트 공유 설정을 `.claude/settings.json`, 프로젝트 개인 설정을 `.claude/settings.local.json`의 JSON으로 설명한다. 관리 설정 및 우선순위도 존재한다. | 실제 Adapter가 생성하는 항목의 문법·의미·권한 적용, 버전별 차이, 관리 정책과 충돌 시 동작 |
| Codex CLI | codex-cli 0.155.1 (`codex --version`) | [공식 설정 문서](https://developers.openai.com/plugins/build/plugins)는 신뢰된 프로젝트에서 `.codex/config.toml`을 로드한다고 설명한다. 이것은 모든 에이전트 정의가 동일 파일로 표현된다는 근거가 아니다. | 실제 Adapter가 생성하는 설정의 형식·의미·프로젝트 신뢰·우선순위와 버전별 동작 |
| Antigravity | 설치 여부 미조사 | [공식 인증 문서](https://antigravity.google/docs/install?tab=cli)는 로컬 표면 간 인증 공유를 설명한다. | 공식 설정 내보내기 형식, 외부 GUI 연동 허용과 계정 격리 |

## 결론과 한계

공식 문서 조회와 `--version`은 설치 여부 및 공개된 형식의 일부에 대한 증거다. 생성기가 없으므로 설정 생성·로딩·손실 변환·권한 집행의 실제 동작은 검증하지 않았다. 사용자 프로젝트나 전역 설정을 수정하지 않았다. ARC-04의 Provider별 실제 동작 검증 완료 조건은 충족되지 않았다. 실제 실험은 OS·CLI·대상 경로·공식 정책을 특정하고 격리된 테스트 환경에서 진행해야 한다. 로그인이나 인증 변경이 필요한 경우 사용자 승인이 선행되어야 한다.

## 설치된 CLI의 도움말 확인

같은 날짜의 `claude --help`는 설정 진단 명령이 현재 디렉터리의 설정을 읽는다고 설명한다. `codex --help`는 설정 옵션과 엄격 설정 검사 옵션을 표시한다. 이는 도움말에서 해당 진입점을 확인한 결과이며 실제 설정 파일이 로드·검증됐다는 증거가 아니다. 사용자 설정이나 인증에 영향을 줄 가능성을 피하기 위해 진단·로그인·실행 명령은 호출하지 않았다. 도움말의 기능과 인자는 관찰한 버전에 한정된다.

## 최초 OS/CLI 및 비용 검토

[Provider MVP 실현 가능성과 비용 검증안](PROVIDER_MVP_FEASIBILITY.md)은 macOS arm64 + Claude Code를 검토 우선 후보로 제안하고 Codex를 비교 대상으로 기록한다. 이는 설치·도움말 및 공식 문서 수준의 확인이며 실제 제품 실행·지원 확정이 아니다. 비대화형 workspace trust 생략, 비용 추정과 구독 청구의 차이, 취소·재개 및 이벤트 손실을 별도 게이트로 둔다.
