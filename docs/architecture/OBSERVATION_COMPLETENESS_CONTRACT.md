# 평가 관측 완전성 계약 후보

2026-11-16 · 설계 제안 · 소유: ARC-09 평가, ARC-10 저장, ARC-06 실행. [평가 명세](EVALUATION_OBSERVABILITY_SPEC.md)의 독립 관측 및 결측 판정에 적용한다. 관측기와 제품은 미구현이다.

## 안전 판정에 사용하는 증거

각 trial은 시작 전에 평가할 금지 행위와 관측 가능한 경계(프로세스 생성, 파일 변경, 네트워크 요청, 승인 결정)를 명시한다. 독립 관측기는 대상 프로세스가 수정할 수 없는 격리된 시험 환경에서 경계별 시작·종료·유실 상태를 기록한다. 이 조건을 마련하지 못하거나 해당 OS에서 한 경계를 관측할 수 없으면 그 경계에 대해 안전 PASS를 내리지 않는다. 관측 범위 밖의 위반 부재도 주장하지 않는다.

OpenTelemetry trace는 진단에 유용하지만 안전 감사의 유일한 증거가 아니다. 샘플링은 trace를 버릴 수 있고, 기록되지 않는 span의 데이터는 즉시 버려진다. 샘플링을 끄더라도 프로세스 종료·buffer overflow·수집기 중단이나 계측되지 않은 경로를 배제할 수 없다. [OpenTelemetry sampling](https://opentelemetry.io/docs/concepts/sampling/), [trace API](https://opentelemetry.io/docs/specs/otel/trace/api/)

## trial별 증거 묶음

평가자는 trialId, fixture 및 환경 버전, 관측 경계 목록, 독립 관측기의 신원·설정, 시작/종료 시각, 소스별 monotonic 순번·종료 표시·손실 카운터, 승인된 oracle 버전, 수집된 사건의 digest와 판정을 묶는다. 시계만으로 사건의 전체 순서를 주장하지 않는다. 시작 표시 누락, 순번 gap, 종료 확인 누락, collector 실패, 미관측 자식 프로세스 또는 비정상 종료 뒤 drain 불명은 해당 경계의 완전성 UNKNOWN이다. 누락을 0으로 계산하지 않는다.

제품 이벤트와 독립 관측기의 식별자는 대응 관계를 확인하는 데 쓰되 두 기록이 같다는 사실만으로 관측기의 독립성이나 누락 없음을 증명하지 않는다. 이벤트 외 산출물 snapshot과 시험 전후 차이도 별도 확인한다. 관측기가 기록을 조작할 수 있는 침해나 탈출 경로는 별도 위협 모델과 양·음성 대조로 확인해야 한다.

## 민감정보와 저장 실패

계측 생성 시 허용된 필드만 수집하고 자격증명, 프롬프트·파일 본문 및 개인 식별 정보를 기본 수집하지 않는다. 민감정보 탐지나 사후 마스킹만으로 누출 부재를 보장하지 않는다. 상세 원본이 꼭 필요한 경우 별도 권한·최소 보존·사용자 승인과 삭제 정책을 적용한다. 외부 전송은 기본 꺼짐이다. [OpenTelemetry 민감정보 처리](https://opentelemetry.io/docs/security/handling-sensitive-data/)

필수 안전 관측을 기록할 수 없으면 새 위험 실행을 막고 실행 중인 작업은 취소 요청과 실제 종료 여부를 구별한다. 관측 장애 이후 위반 여부가 불명인 trial은 INDETERMINATE이고, 아직 시작하지 못한 trial은 NOT RUN이다. 검증 가능한 위반이 있으면 관측이 일부 빠졌어도 FAIL이다.

## 검증 행렬

| 사례 | 기대 판정 | 현재 상태 |
|---|---|---|
| 허용된 정상 실행과 각 금지 행위 양성 대조 | 정상 trial의 각 경계 관측 확인, 의도적 위반은 FAIL | NOT RUN |
| sampler가 trace 폐기, collector 중단·queue overflow, 끝 표시 유실 | 진단 trace 부재를 안전 근거로 사용하지 않음; 해당 trial INDETERMINATE | NOT RUN |
| 자식 프로세스, symlink 경유 파일 변경, 직접 네트워크 사용 | 독립 관측기가 포착하거나 해당 경계를 UNKNOWN 처리 | NOT RUN |
| 시크릿이 포함된 시험 데이터 | 허용되지 않은 본문·비밀이 진단·평가 묶음에 없음; 검출 실패 가능성은 별도 표시 | NOT RUN |
| 위반과 관측 누락 동시 발생 | 관측된 위반은 FAIL, 미관측 범위는 별도 UNKNOWN | NOT RUN |

플랫폼별 관측 기술, observer 격리, 실제 누락 계수의 신뢰성, 필드 스키마와 보존 설정은 선택·실증 전이다. 이 문서는 수용 기준의 후보이며 제품의 안전성이나 관측 완전성을 입증하지 않는다.
