## 6. 동결값 기록

Q2~Q7은 사용자 A(제안 그대로)로 확정. Q8(P1~P12)은 Q9에서 무수정 승인.

### Wire (Q2 확정)

- W1: envelope 양방향 최대 256 KiB, 초과는 부작용 없이 INVALID_INPUT.
- W2: JSON 최대 중첩 32. 초과분은 범위 검사된 페이지·참조로만 취급.
- W3: 문자열 최대 64 KiB.
- W4: 정수 wire 숫자는 수학적 정수값 기준 ±2^53−1. 소수점·지수 표기 우회 거부. 초과 가능 식별자는 부호 없는 10진 문자열. 조용한 타입 변환 금지.
- W5: 유한 소수는 JCS binary64 반올림 수용. 0으로 underflow되는 0 아닌 값과 NaN·무한대 거부.
- W6: 중복 키는 원시 스캔 단계에서 거부. 키 코드포인트·배열 순서 보존, Unicode 정규화 금지.
- W7: 미지 필드 원칙 거부. operation 스키마 명시 필드만 허용. null≠생략, 필수 누락 거부.
- W8: 버전 필드 정수 토큰만, 반올림 무효. 공통 major 부재·minor 비중첩 거부.
- W9: 버전 고정 JCS+SHA-256, 용도별 domain 분리 문자열 고정. bare digest 서명 재사용 금지.

### 시간·보존·만료 (Q3 확정)

- T0: 만료 판정 시각은 Core 기록 UTC.
- T1: 원본 관찰·정규화 이벤트 30일(사용자 단축 가능), 진단 7일, requestId 결과 최소 30일+tombstone workspace 수명, 가져오기 후보 24시간, 작업/시도·승인·산출물 참조는 workspace 삭제까지, 검증된 기억은 삭제·근거 만료까지.
- T2: 설치 등록 1년. 갱신은 사용자 확인, 철회 즉시.
- T3: 실행·전송·적용 승인 발급 후 15분+단회 소비.
- T4: 연결 세션 24시간. 만료·재연결 시 재인증.
- T5: 제안 유효기간 24시간.
- T6: challenge·nonce 5분+단회 소비·원자 기록.
- T7: 비교 코드 시도 5회+만료 10분.
- T8: validation report 버전 변경 시 stale+발급 후 24시간 만료. start 직전 재검증 유지.

### Agent·템플릿·Registry (Q4 확정)

- S1: AgentDefinition v1 필수 필드(ARC-04 v0.2와 동일). 계정·자격증명·실행경로 포함 금지.
- S2: 포트 타입 text·json·artifactRef·control. 동타입 직결만, control은 순서 전용. JSON 세부타입 미표현 시 호환 단정 금지.
- S3: 문자열 64 KiB, inputs·outputs 각 포트 128개, tools·permissions 각 256개, 정의 문서 전체 256 KiB. 포트 상한의 명확화(2026-11-17): 문서 256 KiB 상한과 함께 DoS 경계 유지.
- S4: 버전 표기는 구조화 {major: 정수, minor: 정수}로 통일. ARC-15 "1.0" 문자열 예시는 정식 아님.
- S5: 교환 파일 1 MiB, 노드 1,024개, edge 4,096개, 서브그래프 중첩 깊이 8.
- S6: YAML 사용자 정의 태그·앵커·별칭·병합 키·외부 참조·비문자열 맵 키 전부 거부. v1 별칭 허용 없음.
- S7: JSON Schema dialect Draft 2020-12 고정, 로컬 배포만, 원격 $ref 금지, $schema 선언 필수.
- S8: 노드 6종·관계 7종 확정. 조건·반복·서브그래프 v1 실행 UNSUPPORTED. 무제한 반복·순환은 승인으로도 우회 불가.
- S9: 마이그레이션은 source/target 명시+보존불가 목록+사용자 확인+원본 불변. 자동 마이그레이션 금지.
- S10: UI 배치 정보는 교환 형식 미포함. 클라이언트별 로컬 저장.
- S11: 다중 파일 적용 원자성 미보장. 대상별 결과(Partial/Unknown), 전체 확인 시만 Applied. 재적용은 새 계획+새 승인.

### Analyzer (Q5 확정)

- N1: 제외 기본 목록(자격증명·VCS·의존성·빌드·미디어·아카이브·번들 패턴). 사용자 제외 추가 가능. 기본 제외 해제는 경로 단위 명시만 허용.
- N2: 파일 10,000개, 총 100 MiB, 단일 파일 1 MiB(초과는 메타데이터만), 분석 시간 5분. 상한 도달 시 Partial, 완전한 결과로 표시하지 않음.
- N3: Profile 논리 스키마(profileId·workspaceRef·analyzerVersion·analyzedAt·roots·exclusions·observations·inferences·evidence·uncertainties·limitsReached·userConstraints). 추론은 근거 인용 또는 unknown.
- N4: previewScope → 범위 승인 → analyze → Profile 검토 → ARC-03 전달.
- N5: 기본 로컬 분석만. 모델 전송 시 근거 목록 사전 표시+별도 승인. 원문 전체 전송 금지, 근거 참조 우선. 자동탐지 불완전성 고지.
- N6: 읽은 파일은 경로+크기+mtime+SHA-256, 미읽음은 메타만. 변경 시 재분석 표시, 이전 Profile은 시점 구분 보관.
- N7: 심볼릭 링크를 따라가지 않음. 링크 경로·대상 기록만.

### Runtime·스케줄링 (Q6 확정)

- R1: 이벤트 논리 스키마(eventId·attemptId·source·seq·observedAt·kind·payload). 원본별 순서만 보장, 결측은 gap 명시.
- R2: 단일 attempt wall-clock 상한 24시간. 초과 시 취소 요청 후 Interrupted·Unknown 절차.
- R3: 재시도 Task당 3회. 초과 시 Failed 확정·수동 판단. 간격 1초 시작 지수 백오프(상한 60초). 매 재시도는 새 attempt+새 승인.
- R4: FIFO + DAG Ready 순서. v1 우선순위 없음.
- R5: workspace당 동시 Running 4개 고정(v1).
- R6: v1 선점 없음. 취소는 사용자·정책 요청만.
- R7: PID+프로세스 기동시각 쌍으로 동일성 판단. 단일 PID 금지. 불일치·확인불가면 Unknown.
- R8: 정규화 이벤트 비밀 패턴 마스킹(불완전성 고지). 원본 로그는 별도 권한+30일 보존.
- R9: v1 OS 샌드박스 강제·승인 강제집행 미지원 명시. 강제 불가 범위는 표시하고 해당 위험 행위 차단.
- R10: 실행 중 DAG 수정 금지. 변경은 새 Run으로만. 복구는 Blocked→수동 판단→새 attempt.
- R11: 격리 미검증 시 해당 (installation, accountRef) 조합의 동시 실행 차단.
