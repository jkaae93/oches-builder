# 모듈 경계 계약 검토

검토 기준: 로컬 ARC-01~10 초안과 ARC-00 v0.1. 아래 계약은 설계 제안이며 실제 API 또는 구현된 기능이 아니다. 기능과 인증·세션 지원은 공식 문서와 대상 OS·Provider 버전별 실험 전까지 보장하지 않는다.

| 생산자 → 소비자 | 전달할 논리 결과 | 소비자가 확인할 조건 | 실패 또는 불확실성 |
|---|---|---|---|
| ARC-02 → ARC-03 | Project Profile과 분석 범위·시각·버전·근거 | 목표·제약과 Profile 버전의 적합성 | 일부 탐색 실패·누락을 완전한 분석으로 취급하지 않음 |
| ARC-05 → ARC-03/04/06 | 설치 참조와 Capability 상태·버전·근거, 필요 시 불투명 계정 참조 | 실행 또는 변환에 필요한 기능을 최근 상태로 재검증 | unknown은 supported가 아니며 필수 기능 미확인은 작업 차단 |
| ARC-03 → ARC-04 | 검증 및 사용자 검토를 거친 Proposal 버전 | 제안의 근거·제약과 최신 Capability | 제안 변경이나 입력 노후화 시 재검토 |
| ARC-04 → ARC-09/10 | 대상별 변경 계획·기대 버전 및 승인 요청 | 승인 주체·행위·대상·범위·버전·유효성, 경로와 파일 상태 | 버전 불일치 중단; 부분 적용·결과 불명은 성공이 아님 |
| ARC-07 → ARC-06 | 승인된 작업, 설치·계정 참조, 제한, 요청 ID | 승인·권한·필수 Capability와 저장 가능 여부 | 시작 기록과 외부 실행 사이 장애는 Unknown; 자동 재실행 금지 |
| ARC-06 → ARC-07 | 시도별 상태·관측 결과와 근거 | 정상 종료와 작업의 평가 통과를 별개로 판단 | 취소 요청은 종료가 아니고 Unknown은 Blocked |
| ARC-07 → ARC-09 | 결과·기준·환경 및 출처 | 유효한 기준과 평가 근거 | 평가 불가를 통과로 판단하지 않음 |
| ARC-08 → ARC-06 | 권한을 확인한 선택 컨텍스트와 근거·전송 범위 | 출처·유효 상태와 외부 전송 승인 범위 | 오래되거나 접근 불가한 지식은 무조건 주입하지 않음 |
| ARC-06/07/09 → ARC-10 | 버전이 있는 전이, 감사 정보, 이벤트와 출처 | 적절한 권한, 기대 버전·중복 요청 일치 | 저장 실패는 호출자에게 전달; 외부 실행과 저장을 하나의 트랜잭션으로 가정하지 않음 |
| ARC-02~10 → ARC-01 | 결과·상태·오류와 확인 시각 | 사용자에게 근거, 변경, 미지원·미확인 및 승인 범위 표시 | UI의 표시만으로 실행 통제 또는 정본 기록을 보장하지 않음 |

## 교차 검토 주의점

- 제안 승인, 파일 적용 승인, 실행 및 외부 전송에 대한 정책·승인은 서로 대체하지 않는다.
- 승인 검증 이후 대상 경로나 파일이 바뀔 수 있다. 안전한 OS 접근 수단과 Provider 측 집행의 실효성은 구현 시 별도 검증해야 한다.
- Runtime의 Succeeded는 실행 결과의 정상 종료이고, 작업의 Succeeded는 ARC-09 평가를 통과한 결과다.
- ARC-10의 상태·이벤트 원자적 기록은 요구사항이며 저장 기술에서 검증해야 한다. 프로세스 생성은 그 트랜잭션 밖에 있다.
- 민감한 원본 기록을 포함할 가능성이 있으므로 원본 보존 요구와 수집 최소화·접근 제한을 함께 적용해야 한다. 구체 정책은 미정이다.
