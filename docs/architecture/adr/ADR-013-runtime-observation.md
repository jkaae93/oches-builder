# ADR-013: 외부 실행의 불확실성 보존

상태: 제안 · 2026-11-16 · 관련: ARC-06, ARC-07, ARC-10. 사용자 승인 및 구현 검증 전이다.

## Context
로컬 정본에 실행 시작을 기록하는 작업과 외부 Provider 프로세스를 생성하는 작업은 별도 시스템 경계에 있다. 앱 종료가 두 동작 사이 또는 실행 직후 발생할 수 있다.

## Problem
중복 실행과 잘못된 성공·실패 판정을 피하면서 사용자가 복구할 근거를 남겨야 한다.

## Considered Alternatives
1. 기록 없이 즉시 재시도: 단순하지만 동일 작업이 두 번 실행될 수 있다.
2. 로컬 트랜잭션만으로 정확히 한 번 실행을 가정: 외부 프로세스 생성은 트랜잭션에 포함되지 않아 보장 근거가 없다.
3. 시작 의도와 관찰을 저장하고 불명확한 경우 Unknown으로 남겨 재확인한다.

## Decision
3안을 제안한다. 요청 중복 방지는 동일 요청에 대한 로컬 중복 생성을 줄이되 외부 실행의 정확히 한 번 보장을 주장하지 않는다. 자동 재실행 대신 공식적으로 확인 가능한 근거와 사용자 판단을 사용한다.

## Rationale
확인되지 않은 상태를 확정하거나 재실행하여 외부 부작용을 중복시키는 위험을 줄인다.

## Trade-offs
사용자가 복구를 판단해야 할 수 있고 작업 진행이 지연된다. 일부 Provider는 종료 결과를 사후 조회하지 못할 수 있다.

## Consequences
ARC-06은 Unknown과 관찰 시각을 노출하고, ARC-07은 후속 작업을 차단하며, ARC-10은 요청·상태·관찰 근거를 보존한다. 원본 보존 시 민감정보 보호 정책이 필요하다.

## Verification Requirements
시작 기록 전후, 프로세스 생성 전후, 종료 이벤트 기록 전후에 강제 종료하고 재시작한다. 중복 요청, PID 재사용, 관찰 불가 및 저장 실패를 시험한다. OS와 Provider별 공식 확인 수단을 검증한다.
