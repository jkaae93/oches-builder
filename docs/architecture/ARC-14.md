# ARC-14 Packaging, Distribution & Updates

상태: 상세 설계 제안 v0.1 · 2026-11-16. 제품 배포·서명·스토어 정책은 미검증이다.

## 범위와 불변 조건
Desktop, Core, VS Code 확장, Chrome 확장 및 Native Host의 설치·등록·업데이트·제거를 담당한다. 버전 호환은 ARC-11, 데이터 마이그레이션은 ARC-10, 기본 템플릿 버전은 ARC-15가 소유한다. 초기 후보는 로컬 Desktop과 Core의 동시 설치이며 Desktop 없는 설치와 원격 배포는 검증 전 미지원이다. OS·배포 채널별 최초 버전은 미정이다.

배포물은 검증된 공급망과 OS별 서명·무결성 확인 후 설치하고 실패하면 기존 실행 파일과 데이터 정본을 유지한다. Native Host 경로와 manifest 교체는 권한 보호 및 ARC-11의 Core 신원 재검증을 요구한다. 업데이트 전 백업과 마이그레이션 호환성 확인, 업데이트 중 Core 단일 소유권, 실패 시 이전 실행 파일 복원과 데이터 호환성 검사를 요구한다. 되돌린 바이너리가 새 데이터 스키마를 읽을 수 없다면 자동 실행하지 않고 복구를 요청한다. 제거는 등록 폐기와 앱 제거를 분리하고 사용자 데이터 삭제는 명시적 선택이다. Provider의 공식 인증 정보를 제거하지 않는다.

## 검증 및 한계
정상·중단 설치, 위조·손상 배포물, Core 실행 중 업데이트, 비호환 major, Host manifest 교체, 실패 후 롤백, 이전 버전의 새 스키마 거부, 제거 후 재등록과 사용자 데이터 보존을 OS·패키지별 시험한다. 코드 서명·자동 업데이트·스토어 요구의 실제 수단과 비용, 백업 저장 위치와 복구 절차는 구현 선정 및 사용자 승인 전 미정이다.
