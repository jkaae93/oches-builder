## 검증 증거

- ARC-15 Mermaid 3개는 로컬 Mermaid 파서 및 SVG 렌더링을 통과했다. 레이아웃의 실제 사용성은 평가하지 않았다.
- 문서 내 예시 JSON은 파싱과 최소 키 존재를 확인했다. 이것은 JSON Schema 검증 또는 실행 가능성 검증이 아니다.
- 사용자 요청과 문서 내용의 대응은 위 표를 수동으로 대조했다. Runtime·Storage·인증의 동작 시험은 수행하지 않았다.
- GitHub Projects ARC-15는 `In Review`, P1이다. 상세 설계 문서의 사용자 승인 전이며 `Done`이 아니다.

## 남은 선행 합의

ARC-11의 주체·인증·권한·요청 중복 및 ARC-10 보존 계약은 이후 v0.2 제안으로 보완되었으며, 실제 강제·원자성·내구성과 사용자 승인은 미확정이다. ARC-04의 Agent Definition 및 ARC-07의 포트·실행 계획과 노드 의미를 교차 확정해야 한다. 위 미결정은 문서에서 명시적으로 차단 또는 unknown으로 취급하며, 해결됐다고 주장하지 않는다.
