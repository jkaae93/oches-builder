# OpenSpec

OpenSpec is the workflow for proposing and recording behavior and architecture changes.

- `specs/`: accepted descriptions of current behavior, organized by capability.
- `changes/<change-name>/`: active proposal, delta specs, design, and task checklist.
- `changes/archive/`: completed changes retained for history.
- `config.yaml`: optional project context and rules.

Follow [`../CONTRIBUTING.md`](../CONTRIBUTING.md). Run `openspec init` from the repository root to generate assistant-specific command instructions. Review generated files before committing and preserve project-specific guidance.
