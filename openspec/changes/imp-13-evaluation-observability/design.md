# Design

Follow `ARC-09.md`, `EVALUATION_OBSERVABILITY_SPEC.md`, `OBSERVATION_COMPLETENESS_CONTRACT.md`, `CONTRACT_ACCEPTANCE_MATRIX.md` (X20), and frozen E5/E6.

1. `ArtifactManifestStore` stores workspace artifact snapshots as content-addressed read-only SHA-256 blobs alongside create-only `artifact_manifests` rows bound to `(workspaceID, runID, taskID, attemptID, taskRevision)`. Collection traverses relative paths below the canonicalized workspace root with `O_NOFOLLOW` / `openat`, rejecting symlinks, path traversal, and files modified mid-read (`fstat` before/after). `compareManifestAgainstWorkspace` detects post-snapshot mutations without invalidating immutable historical snapshots or reusing old `PASS` verdicts on new versions.
2. `IndependentObservationVerifier` separates independent observer identity from product sources and enforces V-19 precedence: any observed policy violation yields `FAIL` (while still preserving incomplete boundaries), whereas missing required boundaries, non-isolated observers, active sampling, dropped events, sequence gaps, missing start/end markers, unhealthy collectors, or unobserved child processes yield `INDETERMINATE`.
3. `EvaluationEngine` ties runtime attempt state (`Succeeded`), verified manifest integrity, independent observation completeness, and oracle checks (treating `requireHumanReview` / `AUTO_MATCH_HUMAN_PENDING` as `INDETERMINATE`) into `EvaluationVerdictStore` and `SchedulerRunRepository.applyEvaluation` inside `SQLiteStore.commitSchedulerEvaluation`.
4. `EvaluationEngine.aggregatePairedComparisons` implements deterministic four-category paired accounting (`bothPass`, `baselineOnlyPass`, `candidateOnlyPass`, `bothFail`) plus `incompletePairs` and invalid-batch detection (`duplicate`, `datasetVersion` / `environmentDigest` mismatch). OS-level syscall/network observers and the 20-task human-approved dataset remain product gates outside Core.
