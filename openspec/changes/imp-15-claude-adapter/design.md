# Design

Follow `ARC-05.md`, `ARC-06.md`, `PROVIDER_MVP_FEASIBILITY.md`, `PROVIDER_FORMAT_EVIDENCE.md`, and frozen E3/E4/R1/R2/R8.

1. `CostAccountingEngine` persists append-only `attempt_cost_records` rows keyed by `(attempt_id, revision)` supporting all five canonical states (`AUTHORITATIVE_BILLING`, `PROVIDER_REPORTED_ESTIMATE`, `RATE_TABLE_ESTIMATE`, `SUBSCRIPTION_INCLUDED`, `UNKNOWN`). `UNKNOWN` and `SUBSCRIPTION_INCLUDED` forbid numeric `0` coercion (`amountMicroUSD == nil`); cross-currency totals set `currencyConflict = true` and omit `confirmedTotalMicroUSD`; `consolidateUsage` checks cache overlap (`cached <= total` for included semantics) and event-ID deduplication; `evaluateBudgetGate` fails closed when provider spend enforcement is unverified (including subscription accounts under a monetary cap).
2. `ClaudeCodeAdapter` pins CLI version compatibility (`2.1.296` observed locally), enforces trusted workspace, authenticated account ref, execution + external transfer approvals, verified capabilities (`providerInstall`, `authOfficial`, `runStart`, optional `runResume` + terminal predecessor, `authAccountIsolation`), 24h wall-clock limit, and forbids permission/background bypass flags (`--dangerously-skip-permissions`, `--allow-dangerously-skip-permissions`, `--bg`, `--background`).
3. `parseStreamJSON` and `reconcileOutcome` separate process exit from verified completion: `exit 0` without a non-error terminal `result`, with truncated/malformed output, or with pending background tasks resolves to `Unknown`, never `Succeeded`. Live billable external API execution remains `NOT RUN` until explicit user approval and isolated test credentials are supplied.
